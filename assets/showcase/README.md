# 预生成体验素材

复用本项目原 `assets/demo/` 的 Aholo 客厅（World `3FO4K4RIGVTB`）、家具模型、家具参考图及已计算结构。未复制用户项目目录、原房间照片、密钥或生成记录；上线不发起新的推理。

房间为 Brotli 无损压缩（约 9.83 MiB），家具等为 gzip 无损压缩（家具约 6.8 MiB）。清单记录编码、解压后大小与 SHA-256；运行时校验后解压到体验项目，原始示例包保持不变。没有为了体积预算删减高斯或重建模型。

全部体验文件均低于 ModelScope 普通 Git 的 10 MiB 上限，不依赖构建平台的 Git LFS 拉取行为。Docker 构建会实际建立并验证体验项目，缺少文件或校验不通过时阻止发布。

这些文件仅作为用户授权发布的本项目比赛示例，不对原服务生成内容作额外开源授权声明。模型和房间尺度未经测量，示例尺寸标为未核对。体验项目共用，重开恢复已保存方案；移到最近删除后再次进入可建立新的体验项目。
