# 个人本地 Demo

当前流程是「房间详情 → 进入试摆 → 保存方案／可选生成效果图」。房间照片由 AHOLO World 生成可浏览的高斯空间，家具／装饰照片由 Lux3D 生成三维物品，挂画直接作为图片摆放。地面和候选墙线在本机提取；效果图只用本地 Flux。

## 启动与手机连接

这台电脑已配置依赖。双击「启动本地Demo.cmd」，后台服务启动后会打开首页；再次运行会复用已在线服务。「启动手机网页版.cmd」打开连接手机页。也可在项目目录运行 npm start；终端方式需保持进程运行。只供本机访问用 npm run start:local。

电脑打开 [连接手机](http://127.0.0.1:8787/phone)，手机连接同一受信局域网，输入页面列出的地址与六位配对码。不要在手机输入 127.0.0.1。配对持续八小时，服务重启后需重新配对；程序不会自动修改系统防火墙。配对允许访问电脑中的项目并使用其 AHOLO 额度，本版不用于公网部署。

电脑和手机共用已保存的空间；同一项目建议只由一台设备编辑。页面不会实时合并其他设备的操作；保存冲突时应先保留本机副本，再查看最新保存方案。

换电脑需要 Node.js 22+、用于本地几何提取的 Python／numpy／OpenCV。可通过 AHOLO_PYTHON 指定 Python，运行 setup_local.ps1 安装项目依赖。AHOLO 生成使用安全环境变量 AHOLO_API_KEY，页面只显示是否配置。Flux 还需要独立安装 ComfyUI 与模型权重，见 [本地效果图配置](FLUX_EFFECT_RENDER.md)。

## 准备空间

1. 首页点击「试摆一件物品」，选择一张房间照片和一张落地家具／摆件照片，名称自动填写，描述与尺寸可选。「其他创建方式」保留批量、仅房间及挂画。
2. 保存素材并检查。照片先保存在电脑，检查可解码性、尺寸及清晰度；房间云端输入保持原比例、最长边不超过 2048 像素，原图保留。
3. 确认开始生成后才提交收费任务。场景与物品独立处理，实际进度自动更新，失败时保留已有任务编号和成功物品。
4. 快捷项目两项就绪且仍停留在当前等待页时，自动进入三维预览并尝试首次放入物品；离开后可从该项目继续。普通项目保留手动放入；已有保存方案先恢复，不重复添加。

照片尺寸输入使用厘米，可留空、只填一轴、两轴或三轴；缺轴按首个已填轴（宽、深、高顺序）和模型比例推算。界面区分填写与推算轴，旧数据没有来源时显示未核对。家具尺寸不改变房间尺度。默认尺寸只是预览比例，仍需核对实物。无法解码的 HEIC/HEIF 应先转换，程序不会只改扩展名冒充有效图片。

拍摄要求可展开查看。房间点击「查看照片」、物品点击缩略图可查看整张照片；物品旁的「换照片」直接替换当前照片，新图读取失败会保留原图。取消相册或相机也不会清空已选内容。页面进入后台时会尝试立即暂存草稿，但浏览器可能终止进程，不能将此视为永久备份。

场景明确失败后，可在原项目重新上传场景图片。新图检查并保存后再确认生成；项目名称与物品保留，旧场景图片、World ID 和日志归档至 scene-attempts/。正在生成或提交结果不明时不能直接覆盖；提交中断需先查询原任务，避免重复扣费。

## 试摆

从房间详情的“进入试摆”打开编辑器，返回房间详情前保存有效修改。新旧项目默认简易界面：单指拖物品贴地移动，拖背景浏览，双指缩放；左右转向每次 15°，支持撤销。一段拖动记一次撤销；取消或加入第二指撤回未完成移动，非法移动保留最后有效位置。聚焦物品与整个房间用于换角度。

首件自动位置只是暂定位置，不识别原房间家具占用。放不下时显示待放置卡片，可点位置、改尺寸或校正空间，不自动缩小。删除或清空后不会自动补回。

选中已放置物品，点「核对尺寸」可直接修改，无需进入精调。修改任何一轴时，其余两轴始终按当前比例调整，不做非等比拉伸。更改后越出地面或与新增物品重叠时，整次修改不应用；成功后可撤销，物品原位置、方向和离地高度保留。

「看物品／看房间」可以找回视角。首次拖动提示完成一次有效移动后收起。三维加载显示房间照片和实际加载阶段；切后台暂停绘制并撤回未完成的拖动。画面异常时可点「重试三维画面」，在内存中保留摆放和相机后重建查看器；如果设备或素材仍超出能力，可能继续失败。问号帮助底部可把预览清晰度改为「流畅」，不改变尺寸或导出分辨率。

「精细调整」提供平移、旋转、缩放坐标轴、离地高度与 2D 校正，返回简易试摆即可收起。旧悬空物品不会自动落地。尺寸为厘米，位置为估计米；右上角保存立即保存，问号显示使用说明。

右下角「场景物品」列出当前摆放：缩略图选中，眼睛隐藏／显示，聚焦图标集中视角，垃圾桶移除这一件摆放；移除可撤销，已经建好的物品素材保留。标题中的添加图标可选择我的物品或上传新照片，模型替换是将外部 GLB 用于指定物品。列表可收起。

底部保留浏览、移动、旋转、等比缩放、撤销和更多。看整个房间、地面与墙面显示放在更多中。横屏开关旋转应用内界面，不请求系统全屏、不受手机旋转锁定影响；取消选中恢复竖屏。

默认物品吸附地面；手动位置模式可调整底高。旧贴墙方案保留原位置，后续应用位置时按地面规则处理。新增物品间检查重叠；候选墙线不是可靠的碰撞或自动贴墙依据。

## 2D 空间校正

进入「精细调整」后点「2D」切换平面；地面、墙线、层高和房间比例直接在平面视区中调整，三维试摆中不展开这些校正项。平面始终显示候选墙线，并使用可靠围合限制相机范围。

- 画地面轮廓：逐点勾勒后完成，Esc 取消。通过手绘修改范围，无需输入四个边界坐标。
- 画墙线：点选两端创建；选中已有墙线后拖动端点，可删除选中墙线。相连端点联动，门窗沿所属墙的位置一起更新。
- 地面高度和室内层高校正：层高须在 0.5–20 米内。无效输入保留原有效值。
- 房间比例：等比调整场景、地面、墙面、层高和物品位置，物品实测尺寸不随之放大。超出有效范围时整次校正不应用，可撤销恢复。

完整手绘围合可作为视角边界，零散内部墙线不会变成无限延伸的障碍。没有可靠墙面围合时回退到地面范围；视角还受地面和层高约束。自动识别可能把家具大平面当成墙，需结合点云核对。Z 轴向上，未测量时尺度不是测量级数据。

## 效果图与物品记录

房间详情集中显示房间照片、我的物品和效果图。我的物品包含导入模型、已生成家具／摆件与挂画；点击参考照片可放大。生成中的物品单独显示进度和恢复操作。

在试摆画面调整好机位后，点击顶部相机图标生成当前视角效果图，不另选画幅。横屏出横图、竖屏出竖图，保留完整视野并按模型像素要求留边。生成前自动保存；保存失败不提交推理。个人 ModelScope 出图仍需配置 Token 并确认使用个人额度，本地 Flux 使用电脑显卡。

房间详情可查看多张历史成图，点击放大并切换上一张／下一张。已完成任务从生成记录列表收起，图片与持久化记录保留；进行中、失败和待处理任务仍显示。活动任务约每 4 秒读取状态，无任务时约 15 秒刷新，页面进入后台暂停，返回前台立即更新。查看图片和进度不会创建新任务。

有效编辑自动保存到电脑，保存图标可立即保存。冲突或断线时可保留此设备副本；重进时仅有实质未保存差异才提示恢复。副本留在当前浏览器，不能替代电脑项目备份。电脑高级设置保留布局导入／导出及地面 GLB 导出；手机界面不显示「项目文件与导出」。

## 文件、恢复与删除

项目位于 local-data/projects/<项目ID>/：原素材在 inputs/，任务进度在 project.json，场景在 room.ply，结构在 structure.json／structure.glb，摆放在 placement.json，物品在 objects/。物品任务日志在 object-generations/；Flux 任务与图片在 local-data/effect-renders/。已有项目结构副本不会被重新提取静默覆盖。

关闭页面不会停止仍在运行的电脑服务。重启后复用已有任务编号查询；提交结果不明时不会盲目重提。编辑和结构提取在本机执行，明确生成场景／三维物品时仍需 AHOLO 云端并消耗额度。

首页或详情页删除空间后进入「最近删除」，照片、模型、方案及图片仍保留，可恢复原项目，无需重新生成。当前不自动清空磁盘文件。生成、渲染、上传或保存中的项目暂不能删除；删除不会取消云端任务。

## 范围与验证

当前新建界面只提供单张房间照片。历史视频、多图重建、旧云渲染、空间理解和研究材料已移出当前源码并归档；它们不属于当前入口，也不会自动调用。整理范围见 REPOSITORY_GUIDE.md。

本地提取与手绘校正不保证完整恢复多房间、楼梯、门窗语义或既有家具占用。实体手机的拍照、HEIC、下载、触摸与方向锁定仍需在对应设备核对。完整自动测试用 npm test；历史实测报告各自按记录日期和覆盖范围理解。

消费者改造的状态字段、模块、验证记录与后续范围见 [设计与实现](CONSUMER_TRY_ON.md)。2026-11-09 手机功能改造的浏览器访问授权被拒绝，尚未完成新的可视化验收；不能沿用上一轮截图检查作为本轮已通过的证明。
